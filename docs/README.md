# Dokumentasi Demo

Folder ini disiapkan untuk menyimpan dokumentasi demo project Math Bowl.

## Struktur

```text
docs/
|-- README.md
|-- screenshots/
|   `-- .gitkeep
`-- videos/
    `-- .gitkeep
```

## Panduan Penamaan

Simpan foto atau screenshot ke folder `screenshots/`, misalnya:

- `main-menu.png`
- `mode-tebak-jawaban.png`
- `mode-tebak-operasi.png`
- `deteksi-sarung-tangan.png`
- `game-over.png`

Simpan video demo ke folder `videos/`, misalnya:

- `demo-math-bowl.mp4`
- `demo-mode-tebak-jawaban.mp4`
- `demo-mode-tebak-operasi.mp4`

Setelah file dokumentasi dimasukkan, tautkan file tersebut di bagian
**Dokumentasi Demo** pada `README.md` utama.
